

# Axoria – ICT E-commerce Project

## Project Overview
Axoria is an ICT e-commerce website project inspired by Amazon.
It demonstrates the basic working of an online shopping platform.

## Features
- Homepage with product listings
- Product details page
- Add to cart functionality
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project is developed for academic purposes as part of an ICT practical project.
